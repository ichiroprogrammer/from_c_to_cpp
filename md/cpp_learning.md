### 学習スケジュール

#### 第1週 C++の感じを掴む

**学習内容:**

- 第1章 本書の読み進め方
- 第2章 C++を探検しよう：基本
- 第3章 C++を探検しよう：抽象化メカニズム
- 第4章 C++を探検しよう：コンテナとアルゴリズム
- 第5章 C++を探検しよう：並行性とユーティリティ

## コーディングルール
[コーディングルール](https://github.com/ichiroprogrammer/cpp_docs/blob/main/comprehensive_cpp/V20.11/html/)
のすべてのファイルをgit cloneする必要がある。

**introduction.html**ののリンクから以下の章を読む必要がある。

- プログラミング規約
- コーディングスタイル
- 命名規則
- コメント
- アーキテクチャ

## OOD設計
[OOD設計](https://github.com/ichiroprogrammer/cpp_docs/blob/main/comprehensive_cpp/V20.11/html/)
のすべてのファイルをgit cloneする必要がある。

**introduction.html**ののリンクから以下の章を読む必要がある。


- SOLID
   - 単一責任の原則(SRP)
   - オープン・クローズドの原則(OCP)
   - リスコフの置換原則(LSP)
   - インターフェース分離の原則(ISP)
   - 依存関係逆転の原則(DIP)

- デザインパターン(重要度高)
    - ガード節
    - BitmaskType
    - Pimpl
    - lightweight Pimpl
    - Accessor
    - Copy-And-Swap
    - Immutable
    - NVI
    - RAII
    - DI
    - Singleton
    - State
    - Null Object
    - Templateメソッド
    - Factory
    - Named Constructor
    - Proxy
    - Strategy
    - Observer
    - MVC
    - Cでのクラス表現

- デザインパターン(重要度低)
    - Clone
    - Future
    - Visitor
    - CRTP
